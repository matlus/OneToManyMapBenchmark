# One-to-Many Map Benchmark

C# implementations and benchmarks accompanying Shiv Kumar's explanation of a one-to-many mapping.

- [Article: Custom Data Structure, a One-to-Many Mapping](https://matlus.com/writing/csharp-one-to-many-mapping/)
- [Original source video](https://www.youtube.com/watch?v=e27RquJS_Tc)

The article explains the mapping contract, shared tests, historical measurements and limitations of the original examples.


## Related Design article

[Abstraction in Software Design, with Examples](https://matlus.com/writing/abstraction-in-software-design-examples/) explains how a domain-facing collection can express messages and states over a general mapping structure.
